## 🚀 Your 5-Step Setup Process

### Step 1️⃣ - Create PostgreSQL Database (5 min)
```sql
psql -U postgres

CREATE DATABASE cbt_app;
CREATE USER cbt_user WITH PASSWORD 'SecurePassword123!';
GRANT ALL PRIVILEGES ON DATABASE cbt_app TO cbt_user;
\q
```

### Step 2️⃣ - Create .env Configuration (2 min)
**Option A - Manual:**
Create `.env` file in project root:
```
DATABASE_URL=postgresql://cbt_user:SecurePassword123!@localhost:5432/cbt_app
FLASK_ENV=development
FLASK_DEBUG=True
SECRET_KEY=your-secret-key
```

**Option B - Interactive:**
```bash
python configure_postgres.py
```

## 🆘 Help & Support

### Quick Troubleshooting
1. Check QUICK_REFERENCE.md troubleshooting
2. Run `python test_db_connection.py`
3. Read POSTGRESQL_SETUP_GUIDE.md Troubleshooting section
4. Check PostgreSQL is running (`psql --version`)

### Common Issues

**"Connection refused"**
→ Start PostgreSQL service

**"Role does not exist"**
→ Create user in psql console

**"psycopg2 not found"**
→ Run `pip install psycopg2-binary`

**"no such table"**
→ Run `python init_postgres.py`

**All routes not responding**
→ Run `python test_postgres_routes.py` for diagnostics
