🎯 Introduction

This comprehensive guide will walk you through migrating your Flask CBT application from SQLite to PostgreSQL. PostgreSQL provides superior performance, scalability, and support for concurrent users compared to SQLite.

Why PostgreSQL?

  • Scalability: Handles multiple concurrent connections efficiently
  • Performance: Advanced query optimization and indexing
  • Data Integrity: Full ACID compliance with constraints
  • Cloud Deployment: Native support on Heroku, AWS, Google Cloud
  • Multi-user Support: Proper locking and transaction management
  • Advanced Features: Full-text search, JSON support, arrays
✓ Good News: Your project already has psycopg2-binary installed in requirements.txt, making PostgreSQL integration straightforward!

✅ Prerequisites

Before starting, ensure you have:

  • Python 3.8+ installed
  • Pip package manager
  • Virtual environment activated (.venv)
  • PostgreSQL installed locally OR access to PostgreSQL server
  • Basic knowledge of SQL and Flask
  • PostgreSQL client tools (psql)

🔧 PostgreSQL Installation

Windows Installation

  1. Download PostgreSQL from: https://www.postgresql.org/download/windows/
  2. Run the installer (v15+ recommended)
  3. Set superuser password (remember this!)
  4. Default port is 5432
  5. Optionally install pgAdmin 4 for GUI management

Verify Installation

psql --version

macOS Installation

brew install postgresql@15 brew services start postgresql@15

Linux Installation (Ubuntu/Debian)

sudo apt update sudo apt install postgresql postgresql-contrib sudo systemctl start postgresql

Docker Installation

docker run --name cbt_postgres \ -e POSTGRES_PASSWORD=your_password \ -d -p 5432:5432 \ postgres:15
✓ Tip: Docker is excellent for development as it provides a clean, isolated PostgreSQL instance!

🗄️ Database Setup

Step 1: Create Database and User

psql -U postgres -h localhost

In the PostgreSQL prompt, execute:

-- Create database CREATE DATABASE cbt_app; -- Create user with password CREATE USER cbt_user WITH PASSWORD 'SecurePassword123!'; -- Grant privileges ALTER ROLE cbt_user SET client_encoding TO 'utf8'; ALTER ROLE cbt_user SET default_transaction_isolation TO 'read committed'; ALTER ROLE cbt_user SET default_timezone TO 'UTC'; -- Grant all privileges GRANT ALL PRIVILEGES ON DATABASE cbt_app TO cbt_user; -- Connect and grant schema permissions \c cbt_app GRANT ALL ON SCHEMA public TO cbt_user; GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO cbt_user; GRANT ALL PRIVILEGES ON ALL SEQUENCES IN SCHEMA public TO cbt_user; -- Verify \du -- List users \l -- List databases \q -- Quit

Step 2: Verify Connection

psql -U cbt_user -d cbt_app -h localhost

You should see the prompt:

cbt_app=>
ℹ️ Note: When prompted for password, enter: SecurePassword123!

⚙️ Application Configuration

Step 1: Update Database URI in code1.py

Locate the database configuration section (around line 30) and update:

Current Configuration (SQLite):

app.config['SQLALCHEMY_DATABASE_URI'] = os.environ.get('DATABASE_URL') or 'sqlite:///cbt.db'

New Configuration (PostgreSQL):

app.config['SQLALCHEMY_DATABASE_URI'] = os.environ.get('DATABASE_URL') or 'postgresql://cbt_user:SecurePassword123!@localhost:5432/cbt_app'

Step 2: Initialize PostgreSQL Database

Run the initialization script:

python init_postgres.py
✓ Success: If you see "Database initialized successfully!", tables have been created and sample data has been seeded!

🔐 Environment Variables

Development Setup (.env file)

Create a .env file in your project root:

# PostgreSQL Connection DATABASE_URL=postgresql://cbt_user:SecurePassword123!@localhost:5432/cbt_app # Flask Configuration FLASK_ENV=development FLASK_DEBUG=True SECRET_KEY=your-development-secret-key-change-in-production # Optional: OpenAI Integration OPENAI_API_KEY=your_openai_key_here OPENAI_MODEL=gpt-3.5-turbo OPENAI_TEMPERATURE=0.7 # AWS S3 (if using for file uploads) # AWS_ACCESS_KEY_ID=your_access_key # AWS_SECRET_ACCESS_KEY=your_secret_key # AWS_S3_BUCKET=your_bucket_name

Install python-dotenv

pip install python-dotenv

Update code1.py to Load .env

Add at the top of code1.py:

from dotenv import load_dotenv load_dotenv()

Production Setup (Heroku)

heroku config:set DATABASE_URL=postgresql://user:password@host:5432/dbname heroku config:set FLASK_ENV=production heroku config:set SECRET_KEY=your-production-secret-key heroku config:set OPENAI_API_KEY=your_key

🆘 Troubleshooting

Connection Issues

Error Cause Solution
Connection refused PostgreSQL not running Start service: brew services start postgresql
Role does not exist User not created Create user in psql console
Database does not exist Database not created Execute: CREATE DATABASE cbt_app;
no such table Tables not initialized Run: python init_postgres.py
psycopg2 not found Driver not installed Run: pip install psycopg2-binary

Common Fixes

Fix 1: Reset Database (Development Only!)
python -c "from code1 import app, db; app.app_context().push(); db.drop_all(); print('Database dropped')"
Fix 2: Check Database Connection
psql -U cbt_user -d cbt_app -h localhost -c "SELECT 1"
Fix 3: View PostgreSQL Logs
# macOS tail -f /usr/local/var/postgres/server.log # Linux sudo tail -f /var/log/postgresql/postgresql.log

🚀 Deployment

Heroku Deployment

1 Create Heroku App
heroku login heroku create your-app-name
2 Add PostgreSQL Add-on
heroku addons:create heroku-postgresql:hobby-dev -a your-app-name
3 Set Environment Variables
heroku config:set FLASK_ENV=production -a your-app-name heroku config:set SECRET_KEY=$(python -c 'import secrets; print(secrets.token_hex(32))') -a your-app-name
4 Deploy Application
git push heroku main
5 Initialize Database
heroku run python init_postgres.py -a your-app-name

AWS RDS Deployment

  1. Go to AWS RDS Console → Create database
  2. Select PostgreSQL, v13+
  3. Instance: db.t3.micro (development)
  4. Storage: 20 GB
  5. Public accessibility: Yes (initially)
  6. Get connection endpoint and credentials
  7. Set DATABASE_URL with RDS connection string
