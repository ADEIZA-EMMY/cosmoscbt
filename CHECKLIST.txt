PHASE 2: DATABASE CREATION (5 minutes)
═════════════════════════════════════════════════════════════════════════════

Method 1: Using Command Line (Recommended)
──────────────────────────────────────────

  ☐ Open PostgreSQL console:
     Windows: Start → PostgreSQL 15 → SQL Shell (psql)
     macOS:   Terminal → psql postgres
     Linux:   Terminal → sudo -u postgres psql

  ☐ Copy and paste each of these commands:

     ☐ CREATE DATABASE cbt_app;
     
     ☐ CREATE USER cbt_user WITH PASSWORD 'SecurePassword123!';
     
     ☐ ALTER ROLE cbt_user SET client_encoding TO 'utf8';
     
     ☐ ALTER ROLE cbt_user SET default_transaction_isolation TO 'read committed';
     
     ☐ ALTER ROLE cbt_user SET default_timezone TO 'UTC';
     
     ☐ GRANT ALL PRIVILEGES ON DATABASE cbt_app TO cbt_user;
     
     ☐ \c cbt_app
     
     ☐ GRANT ALL ON SCHEMA public TO cbt_user;
     
     ☐ GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO cbt_user;
     
     ☐ \du  (verify - should see 'cbt_user')
     
     ☐ \l   (verify - should see 'cbt_app')
     
     ☐ \q   (exit)

Method 2: Using pgAdmin 4
──────────────────────────

  ☐ Open pgAdmin 4 from Start Menu
  ☐ Right-click on "Databases" → Create → Database
     ☐ Name: cbt_app
     ☐ Click Create
  ☐ Right-click on "Login/Group Roles" → Create → Login/Group Role
     ☐ Name: cbt_user
     ☐ Go to "Definition" tab
     ☐ Password: SecurePassword123!
     ☐ Click Save
  ☐ Right-click on cbt_app database → Properties → Security
     ☐ Add cbt_user with all privileges


PHASE 3: APPLICATION CONFIGURATION (5 minutes)
═════════════════════════════════════════════════════════════════════════════

Method 1: Interactive Setup (Easiest)
─────────────────────────────────────

  ☐ Open terminal in project root
  ☐ Run: python configure_postgres.py
  ☐ Follow prompts:
     ☐ Database Host: localhost (press Enter)
     ☐ Database Port: 5432 (press Enter)

     ☐ Database User: cbt_user (press Enter)
     ☐ Database Password: SecurePassword123! (type and press Enter)
     ☐ Flask Environment: development (press Enter)
     ☐ OpenAI API Key: (skip - press Enter)
  ☐ Verify .env file created:
     ☐ Open .env in text editor
     ☐ Verify DATABASE_URL is correct
     ☐ Save and close

Method 2: Manual Setup
──────────────────────

  ☐ Create .env file in project root (C:\Users\Admin\Documents\newflask cbtapp\.env)
  ☐ Add these lines (copy and paste):

     DATABASE_URL=postgresql://cbt_user:SecurePassword123!@localhost:5432/cbt_app
     FLASK_ENV=development
     FLASK_DEBUG=True
     SECRET_KEY=your-development-secret-key
     OPENAI_API_KEY=
     OPENAI_MODEL=gpt-3.5-turbo
     OPENAI_TEMPERATURE=0.7

  ☐ Save file
  ☐ Open code1.py
  ☐ Find line 30 (database configuration)
  ☐ Verify it shows: os.environ.get('DATABASE_URL')

ISSUES? TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

If you encounter an issue at any phase:

1. Check QUICK_REFERENCE.md Troubleshooting section (2 min)
2. Run: python test_db_connection.py (1 min)
3. Check POSTGRESQL_SETUP_GUIDE.md (10 min)
4. Verify PostgreSQL is running
5. Verify .env file has correct DATABASE_URL

Common Issues:

  Issue: "Connection refused"
  Fix:   Start PostgreSQL service
  
  Issue: "Role does not exist"
  Fix:   Create user in PostgreSQL
  
  Issue: "Database does not exist"
  Fix:   Create database in PostgreSQL
  
  Issue: "ModuleNotFoundError: No module named 'psycopg2'"
  Fix:   Run: pip install psycopg2-binary
  
  Issue: "no such table"
  Fix:   Run: python init_postgres.py
  
  Issue: "Bad connection string"
  Fix:   Check .env file, fix DATABASE_URL
